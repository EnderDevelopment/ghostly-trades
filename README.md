# Ghostly Trades

Ghostly Trades is a Roblox script designed for the "Ball Tower Defense" game. It adds "ghost units" to trades, enhancing the gameplay experience by introducing new interactive elements. This script is a module that can be integrated into the game to provide additional functionality for handling trades.

## Install

1. Download the `ghost_units.lua` and `ball_tower_defense.lua` files from the GitHub repository.
2. Place the `ghost_units.lua` file in the `ServerScriptService` folder of your Roblox game.
3. Place the `ball_tower_defense.lua` file in the `ServerScriptService` folder of your Roblox game.

## Use

1. Ensure the scripts are server-side scripts.
2. Run the game to see the ghost units in action during trades.
